# MEd Portfolio Game-Style Website

This is a playful, interactive React portfolio to present your MEd (Curriculum & Instruction) outcomes for your defense.

## How to run

1. Install [Node.js](https://nodejs.org/)
2. Open terminal, unzip folder, then run:
    ```
    npm install
    npm run dev
    ```
3. Open `http://localhost:5173/` in your browser

## How to deploy

- Deploy to [Netlify](https://netlify.com/) or [GitHub Pages](https://pages.github.com/) easily. See Vite/React docs.

## Customizing

- Replace avatar images in `/public/avatars`
- Replace roadmap and flag images in `/public/images`
- Edit SLO text/artifacts in `src/data/SLOs.js`
- Add your own PDFs/screenshots to `/public/artifacts`
